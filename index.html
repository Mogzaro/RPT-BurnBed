📋 Setup Guide — 5 Steps to Connect Google Sheets
1
Create Google Sheet
Go to sheets.google.com → New spreadsheet → Name it "RPT Burn & Bed"
2
Open Apps Script & paste code
In Google Sheet → Extensions → Apps Script → Delete all code → Paste the Apps Script code below → Save (Ctrl+S)
3
Run setupSheets() once
In Apps Script: select setupSheets from function dropdown → click ▶ Run
This creates all 5 sheets with correct headers automatically.
4
Deploy as Web App
Deploy → New Deployment → Web App
• Execute as: Me
• Who has access: Anyone
→ Click Deploy → Copy the Web App URL
5
Paste URL above → Test → Sync
Paste the Web App URL in the field above → Test → if ✅ → Sync Now
